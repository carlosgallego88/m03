## EX01 - Variables

Neste exercício foi criado um programa para armazenar e apresentar dados de um estudante.

Foram utilizados diferentes tipos de dados em JavaScript:

- Strings
- Numbers
- Booleans
- Arrays
- Objects

Os dados foram apresentados dinamicamente na página utilizando métodos do DOM.

## EX02 - Conditions

Neste exercício foi criado um sistema de classificação de notas.

Foram utilizadas estruturas condicionais `if`, `else if` e `else` para classificar diferentes intervalos de notas.

Também foi feita uma validação para garantir que a nota introduzida se encontra dentro do intervalo permitido.

## EX03 - Loops

Neste exercício foram utilizados diferentes ciclos para resolver vários problemas.

Foram implementadas funcionalidades para:

- Contar números
- Calcular somas
- Encontrar valores máximos
- Criar uma tabela de multiplicar

Também foram criados exemplos adicionais utilizando `while` e `for...of`.

## EX04 - Functions

Neste exercício foi criada uma biblioteca de funções matemáticas.

Foram implementadas as funções:

- `add`
- `subtract`
- `multiply`
- `divide`
- `average`
- `max`
- `min`

Também foram realizadas validações dos argumentos e da divisão por zero.

## EX05 - Number Analyzer

Neste exercício foi criada uma análise de uma coleção de números.

O programa determina:

- Quantidade de números positivos
- Quantidade de números negativos
- Quantidade de números pares
- Quantidade de números ímpares
- Maior número
- Menor número
- Média

Como estatísticas adicionais, também são apresentados o número de zeros e a quantidade total de elementos.

## EX06 - String Laboratory

Neste exercício foram criadas funções para analisar strings.

Foram implementadas funcionalidades para:

- Contar caracteres
- Inverter texto
- Contar palavras
- Procurar uma palavra
- Verificar se um texto é palíndromo

Também foi feita a normalização do texto utilizando minúsculas e removendo espaços.

## EX07 - Array Toolkit

Neste exercício foram criadas funções próprias para manipular arrays.

Foram implementadas funcionalidades equivalentes a:

- `map`
- `filter`
- `find`
- `reduce`
- `includes`
- `reverse`

Os métodos originais equivalentes não foram utilizados diretamente.

## EX08 - Product Objects

Neste exercício foi criada uma coleção de produtos utilizando objetos JavaScript.

Cada produto contém:

- Nome
- Preço
- Categoria
- Disponibilidade

Foram implementadas funcionalidades de pesquisa, filtragem e ordenação dos produtos.

## EX09 - Dynamic Table

Neste exercício foi criada uma tabela HTML dinamicamente a partir de um array de objetos.

As linhas da tabela são criadas através de JavaScript e manipulação do DOM.

Foram implementadas funcionalidades para:

- Inserir produtos
- Atualizar produtos
- Eliminar produtos
- Atualizar dinamicamente a tabela

As linhas HTML não foram escritas manualmente.

## EX10 - Shopping Cart

Neste exercício foi implementado um carrinho de compras.

O carrinho permite:

- Adicionar produtos
- Remover produtos
- Alterar a quantidade
- Calcular a quantidade total de produtos
- Calcular o preço total
- Esvaziar o carrinho

Também foi utilizada persistência com `localStorage`, permitindo manter o conteúdo do carrinho depois de atualizar a página.
